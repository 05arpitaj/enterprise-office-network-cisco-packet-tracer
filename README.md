# Enterprise Office Network | Cisco Packet Tracer

## Project Overview

Designed and configured a small enterprise network for HR, IT, and Finance departments using Cisco Packet Tracer.

## Technologies Used

- Cisco Packet Tracer
- VLANs
- Trunking
- Inter-VLAN Routing
- DHCP
- DNS
- Static Routing
- NAT Overload
- ACL
- Network Troubleshooting

## Network Design

- VLAN 10 – HR
- VLAN 20 – IT
- VLAN 30 – Finance
- Layer 3 Core Switch for inter-VLAN routing
- Dedicated DHCP and DNS server
- Router and ISP connection
- Simulated Internet server

## Troubleshooting Practice

Practiced L1 troubleshooting for:

- Shutdown switch port
- Incorrect VLAN assignment
- Wrong default gateway
- DNS issues
- Connectivity problems

## Verification Commands

- `show vlan brief`
- `show interfaces trunk`
- `show ip interface brief`
- `show ip route`
- `show ip nat translations`
- `ping`
- `nslookup`
